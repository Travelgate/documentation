# Overview

## API Endpoint

All Activation API operations use this GraphQL endpoint:

```
https://api.travelgate.com/
```

Use the public interactive playground for testing and schema validation: [docs.travelgate.com/playground](https://docs.travelgate.com/playground).

## Overview

The Buyer Activation API flow enables self-service connection setup from buyer integrations.
You can retrieve runtime requirements, execute the connection request, and verify activation state.

### Core Operations in the Flow

- `allOrganizations` (Admin API): identify your `organizationBuyerCode` (`isBuyer = true`).
- `getGroupsByOrg` (Admin API): identify the HotelX `group` to use with that buyer organization when applicable.
- `hotelX.runtimeConfiguration` (HotelX API): discover the parameters required by the supplier you want to connect.
- `activation.connect` (Activation API): submit the connection request.
- `activation.activations` (Activation API): verify status and inspect resulting records.

:::info
The operation and argument names on this page were verified against the live GraphQL schema (`activation` namespace). If the schema changes, this page must be re-verified, not assumed.
:::

## Authentication

All Activation API calls require JWT (JSON Web Token) authentication.
Use the [Admin API Authentication Guide](/docs/apis/for-buyers-and-sellers/admin-api/authentication) to obtain your bearer token.
