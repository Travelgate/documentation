# Hotels File

The Hotels file creates the basic master profiles for the properties in your portfolio. It is the basic catalog that identifies each property and the core information needed to publish and distribute it in the Travelgate marketplace.

The hotel master record is the first step of the **Setup phase**: every room, rate, pricing and restriction record will reference the hotel through its `hotelCode`.

## Purpose

This file usually contains:

- `hotelCode`
- `hotelName`
- `active`
- `email`
- `telephone`
- `fax`
- `address`
- `zipCode`
- `latitude`
- `longitude`
- `categoryCode`
- `categoryName`
- `localityCode`
- `localityName`
- `country`
- `web`

## Field definitions

| Field | Type | Description |
| --- | --- | --- |
| `hotelCode` | String | Unique identifier of the hotel. |
| `hotelName` | String | Commercial name of the hotel. |
| `active` | Boolean | Indicates whether the hotel is active. |
| `email` | String | Contact email address. |
| `telephone` | String | Main phone number. |
| `fax` | String | Optional fax number. |
| `address` | String | Street address. |
| `zipCode` | String | Postal code. |
| `latitude` | Decimal | Geographic latitude. |
| `longitude` | Decimal | Geographic longitude. |
| `categoryCode` | String | Hotel category code. |
| `categoryName` | String | Hotel category label. |
| `localityCode` | String | Locality or city code. |
| `localityName` | String | Locality or city name. |
| `country` | String | Country code. |
| `web` | String | Property website if available. |
