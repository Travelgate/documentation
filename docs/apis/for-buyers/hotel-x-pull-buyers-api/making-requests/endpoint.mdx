# HotelX Endpoint

Travelgate GraphQL APIs use different hosts depending on the product family and the type of operation. For HotelX shopping and booking operations, use:

```text
https://api-shopping.travelgate.com
```

This host is used for operations such as search, quote, book, cancel, booking retrieval, booking amendments (`quote` and `commit`), `oneStepBook`, and `oneStepQuote`.

For other GraphQL domains, the corresponding endpoints are:

| API family | Endpoint |
| --- | --- |
| Shopping and booking flow | `https://api-shopping.travelgate.com` |
| Content and static master data | `https://api-content.travelgate.com` |
| Stats, logging, admin and other shared APIs | `https://api.travelgate.com` |

Use the endpoint associated with the specific operation you are calling, instead of sending all requests to the same host.
