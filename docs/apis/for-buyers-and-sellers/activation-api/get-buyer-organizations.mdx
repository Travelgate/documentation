# Get Buyer Organizations (Seller)

This step is only required in the **Seller flow**. In seller mode, the `organizationBuyerCode` is retrieved from the following endpoint:

```text
GET https://app.travelgate.com/api/gateway-proxy/orgs?includeTest=false
```

From the response, select the buyer organization you want to connect and use its `organizationsData.code` as `organizationBuyerCode` in `connect`.

Pick only entries where `organizationsData.isBuyer` is `true`.

## Response Example

```json
{
  "node": {
    "organizationsData": {
      "code": "codeTest",
      "label": "Buyer Test",
      "isBuyer": true,
      "isSeller": false,
      "isTest": false
    }
  }
}
```

In this example, `organizationBuyerCode` would be `codeTest`.

:::info
Buyers resolve their own organization code via the Admin API `allOrganizations` query (where `isBuyer = true`). See [Get Organizations](/docs/apis/for-buyers-and-sellers/admin-api/get-organizations) for details.
:::
