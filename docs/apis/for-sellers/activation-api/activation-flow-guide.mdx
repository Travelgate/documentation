# Seller Activation Flow Guide

This page documents the complete seller self-service activation cycle.

## End-To-End Seller Flow

1. Get buyer organizations and identify the target `organizationBuyerCode` for the buyer to connect with.
2. Call `hotelX.runtimeConfiguration(supplierCode)` to discover the parameters required by the target supplier.
3. Execute `activation.connect(data: ActivationConnectInput!)` using:
   - `organizationBuyerCode` (required).
   - `accessConfiguration` (`AccessInput`) with `supplier` and the `parameters` discovered in step 3.
4. Verify status with `activation.activations(data: ActivationReadInput!)`.
