# Connect

Use `connect` to submit the activation request on behalf of the target buyer. The input type is `ActivationConnectInput`.

## Seller Input Context

Build the request with:

- `organizationBuyerCode` (required) — the target buyer's organization code.
- `notificationEmail` (optional) — addresses notified when the activation completes.
- `accessConfiguration` (required, `AccessInput`) — at minimum `supplier`, and the `parameters` (`key`/`value` pairs) required by that supplier, as discovered in [Get Runtime Configuration](runtime-configuration.mdx).

Resolve the buyer organization code before calling `connect`.

## Mutation Overview

```graphql
mutation Connect($data: ActivationConnectInput!) {
  activation {
    connect(data: $data) {
      code
      activationData {
        status
      }
    }
  }
}
```
