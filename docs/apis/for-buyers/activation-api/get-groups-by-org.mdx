# Get Groups By Org (Admin API)

This step is only required when the buyer organization has **more than one HotelX group**. If you are unsure how many groups the organization has, run the `allGroups` Admin API query to find out.

When the response returns more than one entry under `edges`, the `group` field becomes **mandatory** in the `connect` mutation. Use the `code` of the group that has always been used in the activation forms in My Connections.

For the full query documentation, inputs, and interactive playground, see [Get Groups](/docs/apis/for-buyers-and-sellers/admin-api/get-groups).
