# Get Activations

Use `activations` to verify created connections and inspect status after `connect`. The input type is `ActivationReadInput`.

## Query Overview

```graphql
query Activations($data: ActivationReadInput!) {
  activation {
    activations(data: $data) {
      edges {
        node {
          code
          activationData {
            status
          }
        }
      }
    }
  }
}
```

### Buyer Example

```json
{
  "data": {
    "organizationBuyerCode": "BUYER_ORG_CODE"
  }
}
```

### Seller Example

```json
{
  "data": {
    "organizationSellerCode": "SELLER_ORG_CODE",
    "organizationBuyerCode": "BUYER_ORG_CODE"
  }
}
```

See the [GraphQL API Reference](/api) under the `activation` namespace for the full `activations` field tree. `status` is one of `PENDING`, `AVAILABLE`, `MANUAL`, or `PENDING_SELLER_RESOLUTION`.

## Operational Use

- Confirm whether the activation already exists.
- Validate the final state after `connect`.
- Track activation state from buyer or seller systems.
