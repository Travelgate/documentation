# Buyer Activation Flow Guide

This page documents the complete buyer self-service activation cycle.

## End-To-End Buyer Flow

1. Retrieve `organizationBuyerCode` with [Get Organizations (Admin API)](get-organizations.mdx).
2. Resolve the HotelX `group` with [Get Groups By Org (Admin API)](get-groups-by-org.mdx) when the buyer organization has multiple groups.
3. Call `hotelX.runtimeConfiguration(supplierCode)` to discover the parameters required by the target supplier.
4. Execute `activation.connect(data: ActivationConnectInput!)` using:
   - `organizationBuyerCode` (required) and `group` (required when multiple buyer groups exist).
   - `accessConfiguration` (`AccessInput`) with `supplier` and the `parameters` discovered in step 3.
5. Verify status with `activation.activations(data: ActivationReadInput!)`.

:::tip
For the exhaustive list of arguments and selectable fields for each operation, see the [GraphQL API Reference](/api/) under the `activation` namespace (and `hotelX` for `runtimeConfiguration`).
:::
