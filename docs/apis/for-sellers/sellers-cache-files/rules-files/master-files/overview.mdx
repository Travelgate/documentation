# Overview

Master Files define the supplier's foundational product structure. They contain the hotel, room, and rate definitions that describe how the commercial offer is organized and under which conditions it can be sold.

This group is the backbone of a Rules File integration. Without accurate master data, pricing files cannot be interpreted correctly.

## Included file types

- [Hotels](./hotels.mdx)
- [Rates](./rates.mdx)
- [Rooms](./rooms.mdx)

## How these files work together

The standard logic is:

1. the hotel is defined in the Hotels file
2. rates are defined in the Rates file, each linked to a hotel through `hotelCode`
3. room types are defined in the Rooms file, each linked to a rate through `rateCode`
4. pricing and restrictions are then loaded into the rate and room combination (see [Pricing Files](../pricing-files/overview.mdx))

This creates a clear and consistent relationship between catalog structure and commercial conditions.
