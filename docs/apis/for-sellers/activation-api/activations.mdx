# Get Activations

Use `activations` to verify created connections and inspect status after `connect`. The input type is `ActivationReadInput`.

## Query Overview

```graphql
query Activations($data: ActivationReadInput!) {
  activation {
    activations(data: $data) {
      edges {
        node {
          code
          activationData {
            status
          }
        }
      }
    }
  }
}
```

```json
{
  "data": {
    "organizationSellerCode": "SELLER_ORG_CODE",
    "organizationBuyerCode": "BUYER_ORG_CODE"
  }
}
```

See the [GraphQL API Reference](/api/types/objects/activation-connection.mdx) for the full `activations` field tree (status values, identifiers, and every other selectable field), kept in sync with the live schema. `status` is one of `PENDING`, `AVAILABLE`, `MANUAL`, `PENDING_SELLER_RESOLUTION`.

## Operational Use

- Confirm whether activation already exists.
- Validate final state after `connect`.
- Track activation state from seller systems.
