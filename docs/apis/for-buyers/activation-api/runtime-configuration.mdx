# Get Runtime Configuration

Before calling `connect`, discover which parameters the target supplier requires using the **HotelX API**'s `runtimeConfiguration` query. This is not part of the `activation` namespace — it lives under `hotelX`, but it is the prerequisite step for building a valid `AccessInput.parameters` list in `connect`.

:::info
If you are following the Buyer flow, run this call after `allOrganizations` and `getGroupsByOrg`, then continue with [Connect](connect.mdx).
:::

## Relationship to the Connector RuntimeConfiguration Model

The `hotelRuntimeParameters` returned here follow the same model documented for Connectors — see [RuntimeConfiguration (Connectors Pull Sellers API)](/docs/apis/for-sellers/connectors-pull-developers-api/advanced-configuration/runtime-configuration.mdx) for the full field-by-field definition (`key`, `mandatory`, `type`, `possibleValues`, `pattern`, etc.). This page does not repeat that definition; it documents how to request it through the public GraphQL API.

## Query Overview

```graphql
query RuntimeConfiguration($supplierCode: ID!) {
  hotelX {
    runtimeConfiguration(supplierCode: $supplierCode) {
      hotelRuntimeConfigurationData {
        hotelRuntimeParameters {
          key
          mandatory
          type
          defaultValue
          possibleValues
        }
      }
    }
  }
}
```

```json
{
  "supplierCode": "SUPPLIER_CODE"
}
```
