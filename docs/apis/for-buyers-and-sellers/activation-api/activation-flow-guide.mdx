# Activation Flow Guide

This page documents the complete Activation flow for both Buyer and Seller profiles.

## Buyer Flow

1. Resolve your buyer organization code with [Get Organizations](/docs/apis/for-buyers-and-sellers/admin-api/get-organizations).
2. If the buyer organization has more than one HotelX group, resolve the correct group with [Get Groups](/docs/apis/for-buyers-and-sellers/admin-api/get-groups).
3. Call `hotelX.runtimeConfiguration(supplierCode)` to discover the parameters required by the target supplier.
4. Execute `activation.connect(data: ActivationConnectInput!)` using:
   - `organizationBuyerCode`.
   - `group` when the buyer has multiple groups.
   - `accessConfiguration` (`AccessInput`) with `supplier` and the runtime parameters discovered in step 3.
5. Verify status with `activation.activations(data: ActivationReadInput!)`.

## Seller Flow

1. Resolve the target buyer organization code with [Get Buyer Organizations (Seller)](get-buyer-organizations.mdx). Select only organizations where `isBuyer = true`.
2. Call `hotelX.runtimeConfiguration(supplierCode)` to discover the parameters required by the target supplier.
3. Execute `activation.connect(data: ActivationConnectInput!)` using:
   - `organizationBuyerCode` for the target buyer.
   - `accessConfiguration` (`AccessInput`) with `supplier` and the runtime parameters discovered in step 2.
4. Verify status with `activation.activations(data: ActivationReadInput!)`.

## Role Differences at a Glance

| Topic                | Buyer                                                      | Seller                                               |
| -------------------- | ---------------------------------------------------------- | ---------------------------------------------------- |
| Organization scope   | Uses its own `organizationBuyerCode`                       | Uses the target buyer `organizationBuyerCode`        |
| Group resolution     | May need `group` when the buyer has multiple HotelX groups | Typically does not resolve buyer group in this flow  |
| Activation ownership | Creates the activation request for its own organization    | Creates the activation on behalf of the target buyer |

:::tip
For the exhaustive list of arguments and selectable fields for each operation, see the [GraphQL API Reference](/api/) under the `activation` namespace and `hotelX` for `runtimeConfiguration`.
:::
