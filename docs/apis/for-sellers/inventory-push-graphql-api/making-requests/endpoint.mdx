# API Endpoint

Travelgate GraphQL APIs use different hosts depending on the operation family. For Inventory Push operations, use:

```text
https://api-inventory.travelgate.com
```

This endpoint is used for inventory-related requests such as `availDerivedRates`, `availRates`, `availOffers`, and other inventory setup and retrieval flows.

Explore the Inventory schema in the [Inventory API Playground](https://api-inventory.travelgate.com/graphql/playground).
