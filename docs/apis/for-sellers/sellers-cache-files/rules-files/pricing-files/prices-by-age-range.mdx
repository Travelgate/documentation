# Prices by Age Range File

In the Prices by Age Range file, each guest is priced according to the age bracket they fall into, using the format `AgeFrom-AgeTo,Amount,Type`. This is especially useful for family or child-inclusive rate structures.

## Purpose

This file is used when each guest age group has a different price or discount. Typical ranges are:

- `0-2`
- `3-12`
- `13-99`

## Example

[Download the example Prices by Age Range file (CSV)](https://stplaformwe.blob.core.windows.net/docs/sellerfiles/rulesfile/prices_by_age_range.csv)

## Field definitions

| Field | Type | Description |
| --- | --- | --- |
| `hotelCode` | String | Hotel identifier. |
| `rateCode` | String | Rate plan identifier. |
| `priceCurrency` | String | Currency of the price. |
| `roomCode` | String | Room type. |
| `startDate` | Date | Start date of the pricing range. |
| `endDate` | Date | End date of the pricing range. |
| `minLengthOfStay` | Integer | Minimum LOS rule. |
| `maxLengthOfStay` | Integer | Maximum LOS rule. |
| `durationDays` | Integer | Rule duration. |
| `basePrice` | Decimal | Reference base price for the age-based logic. |
| `pricesByAgeRange` | String | Price definition by age range in the format `AgeFrom-AgeTo,Amount,Type`. |

## Understanding complex fields

Because CSVs are flat, we use specific delimiters (`,` and `|`) to send lists inside a single cell.

### `pricesByAgeRange`

List of objects — separate different age brackets with a pipe `|`.

- **Format**: `AgeFrom-AgeTo,Amount,Type | AgeFrom-AgeTo,Amount,Type...`
- **Example**: `0-2,0.00,AMOUNT|3-12,25.00,AMOUNT|13-99,80.00,AMOUNT`
- **Meaning**: ages 0-2 pay 0.00, ages 3-12 pay 25.00, ages 13-99 pay 80.00, all as fixed amounts.

## Notes

This model is especially useful when the Seller needs to calculate pricing according to the guest age distribution rather than a fixed adult-based rate.
