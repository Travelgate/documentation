# Overview

## API Endpoint

All Activation API operations use this GraphQL endpoint:

```
https://api.travelgate.com/
```

Use the public interactive playground for testing and schema validation: [docs.travelgate.com/playground](https://docs.travelgate.com/playground).

## Overview

The Activation API supports both Buyers and Sellers. Buyers use it to request self-service connections for their own organization. Sellers use it to request and validate connections on behalf of a target buyer.

### Core Operations in the Flow

- Resolve the target `organizationBuyerCode`.
- If the buyer has more than one HotelX group, resolve the correct `group` before calling `connect`.
- Call `hotelX.runtimeConfiguration` to discover which runtime parameters the supplier requires.
- Call `activation.connect` to submit the activation request.
- Call `activation.activations` to verify the created connection and inspect its status.
- When your workflow requires it, call `activation.validate` to validate an existing access for one or more client names.

:::info
The operation and argument names on this page were verified against the live GraphQL schema under the `activation` namespace. If the schema changes, this page must be re-verified against the schema and the GraphQL API Reference.
:::

## Authentication

All Activation API calls require JWT (JSON Web Token) authentication. Use the [Admin API Authentication Guide](/docs/apis/for-buyers-and-sellers/admin-api/authentication) to obtain your bearer token.
